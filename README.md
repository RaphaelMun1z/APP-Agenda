# SchedLaunch

<img src="assets/schedlaunch_logo.png" alt="Logo do SchedLaunch" width="360" />

O **SchedLaunch** é uma agenda visual para organizar tarefas, compromissos e atividades de estudo, trabalho e vida pessoal. Os compromissos aparecem em cards distribuídos por data, facilitando a consulta dos horários, dos prazos e do que ainda precisa ser feito.

Você pode criar e editar atividades, organizá-las em categorias e subcategorias com cores e ícones, mover os cards entre datas e marcar tarefas como concluídas. Os filtros ajudam a encontrar compromissos por data, período ou categoria e podem ser recolhidos para deixar mais espaço para a agenda.

As alterações são salvas automaticamente no navegador utilizado. Também é possível exportar uma cópia de segurança da agenda e importá-la para recuperar seus compromissos. A interface se adapta ao computador e ao celular.
